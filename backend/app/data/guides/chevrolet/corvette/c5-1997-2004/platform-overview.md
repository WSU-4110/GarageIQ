# Platform

The C5 Corvette was built for the 1997 to 2004 model years. It was the first Corvette with a hydroformed box frame, a rear-mounted transaxle linked to the engine by a torque tube, and the first GM car with the LS engine family. This gives roughly a 50/50 weight balance.

# Engine and transmission

The LS1 V8 made 345 hp initially and 350 hp from 2001. Automatics use the 4L60-E. Manuals use a Borg-Warner T-56 6-speed. The manual has computer-aided gear shifting (skip shift, 1st directly to 4th under light load), which can be disabled with PCM tuning or an aftermarket eliminator.

# Body styles

The fastback coupe came first in 1997, the convertible in 1998, and the fixed-roof coupe in 1999. The Z06 is the high-performance variant, so confirm whether a part is for the Z06 or the base car.

# Suspension options

Base cars have the FE1 suspension. FE3 sport suspension came with the Z51 package. F45 Selective Ride Control allowed ride mode selection, replaced from 2003 by F55 Magnetic Selective Ride Control. The Active Handling system was standard on 2001 and later cars. Know which suspension your car has before buying shocks or springs, because selective ride cars need compatible parts.
