# What each car is

The Si is a sedan or coupe with the 1.5 L turbo engine and a 6-speed manual only. The Type R is a hatchback with a 2.0 L turbocharged i-VTEC engine, also manual only. They have different engines, so intake, intercooler, downpipe and tune parts are not interchangeable between them.

# Common upgrades

Both respond to an ECU tune, a drop-in or full intake, and a front-mount intercooler or improved cooling for repeated hard use. Exhaust changes affect legality and noise, so check local rules. Brake pads, fluid and tires improve track use more than extra power.
