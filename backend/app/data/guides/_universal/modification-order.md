# Start with maintenance

Fix leaks, overdue fluids and worn parts before modifying. Modifications amplify existing problems, so a healthy baseline matters more than any single part.

# Tires and brakes before power

Grip and stopping power are the limiting factors on the street. Quality tires, fresh brake fluid and good pads make a car faster and safer than the first bolt-on.

# Power last, and as a package

Intake, exhaust and tune work best together. Buy supporting parts first so the tune is made once for the final setup.
